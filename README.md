# 📈 AI Stock Screener

AI based stock analysis system using Python, Machine Learning and Streamlit.

## Features

- Stock Data Analysis
- SMMA Trend Indicator
- RSI Momentum Analysis
- MACD Signal Detection
- Machine Learning Prediction
- Risk Management
- Stop Loss & Target Calculation
- Interactive Streamlit Dashboard


## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- Streamlit
- Plotly
- Joblib


## Project Flow

Stock Data
↓
Indicators Analysis
↓
Machine Learning Model
↓
Risk Management
↓
Trading Recommendation
